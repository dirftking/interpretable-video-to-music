# Interpretable and Controllable Video-to-Music Generation

**Peiqi Zhu** · Independent Researcher

[Read / download PDF](./paper.pdf)

## Abstract

With the growth of online digital media, automated background-music generation has become an important task for content creation. Although current generative models can produce high-quality audio from text prompts, static descriptions cannot fully represent complex and time-varying video information. To address this limitation, we propose an interpretable and controllable video-to-music generation framework. The system uses a dual-stream architecture to capture scene semantics, visual rhythm, motion intensity, and emotional changes across temporal segments. These features are integrated into an intermediate Music Condition Representation, denoted by C_V, which describes tempo, rhythmic density, instrumentation, dynamics, musical structure, and continuous affective trajectories. A conditional music generator G then uses this representation to produce background music M. The proposed design aims to improve semantic, emotional, and temporal alignment while allowing users to modify individual musical attributes. Because full model training has not yet been completed, the experimental section reports literature-calibrated simulation results rather than empirical measurements.
